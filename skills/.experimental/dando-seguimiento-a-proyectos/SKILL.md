# Seguimiento de Proyectos

Cuando se trabaje en, o se pregunte por, una iniciativa con un objetivo:

1. Nombra el objetivo concreto de la iniciativa en una línea. Si no está explícito en la conversación, pregúntalo antes de reportar avance — nunca asumas uno.
2. Compara el estado actual contra ese objetivo: qué está hecho, qué falta, qué está bloqueado.
3. Identifica el riesgo más urgente para llegar al objetivo — uno solo, no una lista exhaustiva.
4. Cierra siempre con el siguiente paso: una acción concreta con verbo y, si aplica, un dueño. Una frase como "seguir trabajando" o "continuar" no es un siguiente paso válido.

## Formato de reporte

```
Objetivo: [una línea]
Avance: [% o hito alcanzado]
Riesgo principal: [uno]
Siguiente paso: [acción + dueño]
```
